# Portafolio Nakuma

Sitio web del Portafolio de Experiencias de Nakuma Casa Cultural.

## Desarrollo

```bash
npm install
npm run dev
```

## Imágenes

Sube estas imágenes a `public/images/` con estos nombres:

- `hero.jpg` — imagen principal de portada, idealmente comunidad + territorio.
- `territorio.jpg` — recorrido o vista territorial.
- `universidades.jpg` — estudiantes/docentes en trabajo de campo.
- `colegios.jpg` — experiencia pedagógica con jóvenes.
- `empresas.jpg` — trabajo colaborativo o voluntariado.
- `sector-financiero.jpg` — manos, diagnóstico o proceso comunitario.
- `manos.jpg` — detalle de trabajo colectivo con manos.
- `impacto.jpg` — comunidad reunida o actividad de impacto.

El CSS aplica blanco y negro automáticamente a varias fotos y añade los colores neón desde la interfaz, así que las imágenes pueden ser fotos normales.

## Identidad visual

Paleta principal:

- Verde: `#0DF19A`
- Crema: `#F4EBD7`
- Negro: `#0B0B0B`
- Morado: `#8A00FF`
- Amarillo: `#FFE600`
- Naranja: `#FF6A00`
- Cyan: `#54D1E3`

Tipografías temporales: Permanent Marker + Montserrat. Puedes reemplazar Permanent Marker por la tipografía handmade definitiva.

3. Subir las 8 fotografías.
